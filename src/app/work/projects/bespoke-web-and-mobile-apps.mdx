## Overview

A curated collection of client-commissioned software projects spanning cross-platform mobile apps and responsive web interfaces. Each solution was designed and implemented autonomously, from initial requirement discovery to production deployment.

## Technical Scope

- **High-Performance Web Frontend**: Built modern web portals utilizing Next.js, TypeScript, and fine-tuned CSS modules for maximum rendering speed and sub-second Largest Contentful Paint (LCP).
- **Mobile Client Engineering**: Constructed clean user experiences using Flutter and React Native with persistent local storage, secure authentication flows, and real-time synchronization.
- **RESTful API & Database Design**: Designed predictable JSON APIs backed by PostgreSQL and Prisma ORM, featuring typed validation schemas and structured error handling.
- **Client Delivery & Iteration**: Maintained active communication loops, delivering staged milestones and automated CI/CD previews throughout the development cycle.

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, SCSS Modules
- **Mobile**: Flutter, React Native
- **Backend & Database**: Node.js, Express, PostgreSQL, Supabase
- **DevOps**: Vercel, GitHub Actions

## Outcome

Successfully shipped functional, maintainable products on schedule, helping independent businesses and teams streamline customer booking and internal data workflows.
