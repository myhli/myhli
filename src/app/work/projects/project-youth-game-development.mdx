## Overview

Project Youth is a collaborative project created alongside school peers to develop an interactive visual novel featuring the official mascot of SMK Raden Umar Said (Kudus). As a **Game Coder**, I contributed directly to the game's production using the **Ren'Py** engine and **Python**, focusing on narrative scripting, dialogue pruning and pacing, branching story routes, and an interactive character destiny meter.

## Key Implementations

- **Ren'Py & Python Scripting**: Programmed core narrative game logic, scene transitions, visual assets integration, and audio cues using Ren'Py's scripting engine and Python.
- **Dialogue Pruning & Pacing**: Collaborated closely with the narrative team to prune and refine dialogue scripts, ensuring conversations feel natural, engaging, and well-paced for players.
- **Branching Route System**: Designed and implemented multi-route story architecture where player choices dynamically alter plot directions and unlock unique narrative paths.
- **Character Destiny Meter**: Engineered a variable-driven destiny meter calculation system that tracks cumulative player decisions across key story beats to determine character outcomes and multiple distinct endings.

## Technology Stack

- **Game Engine**: Ren'Py Engine
- **Programming Language**: Python / Ren'Py Script
- **System Architecture**: Dialogue Pacing Engine, Multi-Branching Route Logic, Character Destiny Tracker
- **Tools**: Visual Studio Code, Git

## Outcome

Delivered an engaging, responsive visual novel showcasing the SMK RUS mascot, featuring dynamic player-driven story branches, refined dialogue flow, and an interactive character destiny mechanic.
